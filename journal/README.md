# Research journal

A daily log of study, experiments and decisions. It helps you be honest about what was tried, including failures and abandoned ideas, which matters for judging how many trials a result really took.

- One file per day: `journal/YYYY/YYYY-MM-DD.md`, copied from [`TEMPLATE.md`](TEMPLATE.md).
- Link every experiment to a commit hash and config.
- Record hold-out uses explicitly.
- Weekly reviews go in `journal/YYYY/week-NN-review.md` (template coming in M8, [#8](https://github.com/Sportx666/sistematic_trading/issues/8)).
